# PromeFTP 1.1.3

- Save an agent client token for installed skills from the one-time token window. The PromeFTP CLI reads the saved credential automatically, so you do not need to copy it into each agent runtime. The token stays out of skill files. It is stored as plain text in a user-only `0600` file and is removed when you forget it or revoke its client.
- Reduce clutter in **Settings → Agents** with short labels, expandable help, and a five-item recent activity view. Full activity remains available through filters and JSON export.
- Accept PAM gateway usernames that contain multiple `@` separators, such as `account@host@account@host`.

The saved-token option is explicit and optional. Existing environment-variable tokens continue to work. Requires macOS 13 or later on Apple Silicon. See the [user guide](../USAGE.md), [agent setup](../AGENTS.md), and [install guide](../INSTALL.md).
