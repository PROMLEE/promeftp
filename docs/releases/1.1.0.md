# PromeFTP 1.1.0

PromeFTP now includes a local CLI and API so compatible AI agents can use connections you explicitly authorize.

- **Grant access per agent and bookmark.** Enable agent access only when needed, register clients, and choose the saved connections and capabilities each one may use.
- **Run SSH tasks with clear limits.** Expose fixed commands or require one-time approval for an exact command. SSH commands run with the remote account's permissions.
- **Use SFTP safely.** Agents can list and inspect approved directories, with downloads as a separate grant. The agent SFTP API does not modify or delete remote files.
- **Use PAM answers and terminal triggers.** Select which saved authentication rules and trigger notifications an agent can use.
- **Review activity.** Local history records requests, grants, approvals, sessions, and outcomes without storing credentials, terminal output, or arbitrary command text.
- **Install agent skills.** Install or update the PromeFTP skill for Codex, Claude Code, Cursor, Gemini CLI, and GitHub Copilot CLI, at user or project scope.
- **Open-source MIT license.** The application source is published in this repository. See [LICENSE](../../LICENSE) and [third-party notices](../../THIRD-PARTY-NOTICES.md).

Agent access is off by default. PromeFTP must be open. This release supports direct saved bookmarks with explicit usernames; OpenSSH aliases, custom SSH configurations, proxies, and jump hosts are not supported for agent sessions. SSH command permissions depend on the remote account. Requires macOS 13 or later on Apple Silicon.
