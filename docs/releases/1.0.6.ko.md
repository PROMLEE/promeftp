# PromeFTP 1.0.6

OpenSSH 별칭 연결 화면을 더 명확하고 편집하기 쉽게 개선했습니다.

- **연결 이름을 맨 위에 표시.** Name 입력란을 목적지 위로 옮겼습니다. OpenSSH 별칭을 선택하면 별칭이 표시 이름의 기본값이 됩니다.
- **해석된 설정을 편집 가능한 값으로 입력.** OpenSSH config의 Hostname/IP, 사용자, 포트, 키를 흐린 안내문 대신 각 입력란에 채웁니다. 값을 직접 수정할 수 있고 지우면 config 값을 다시 사용합니다. 별칭 접속은 유지되어 별칭에 지정한 OpenSSH 규칙도 적용됩니다.
- **직접 주소 변환 유지.** 별칭 대신 해석된 주소로 접속하려면 **Use address**를 선택합니다.

활성 세션을 닫은 뒤 **PromeFTP → Check for Updates…**를 선택하세요. 새로 설치하려면 Apple Silicon DMG를 받으세요. macOS 13 이상이 필요합니다.
