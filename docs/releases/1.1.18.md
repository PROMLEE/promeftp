# PromeFTP 1.1.18

## What's changed

- Automatic updates install again. PromeFTP 1.1.15 and 1.1.17 could download an update and then failed with "An error occurred while launching the installer." The release archives were missing Sparkle's updater helper, and this build includes it.
- Keyboard shortcuts: in Preferences → Shortcuts, click a shortcut itself to change it, then press the new keys. Press Escape to cancel or Delete to clear it.

## Known issues

- Korean, Chinese, and Japanese text in the terminal is wide with the default Menlo font. Choose a monospaced font that includes these characters in Settings → Terminal.
- Some labels in Korean, Japanese, and Chinese are machine translated and may read awkwardly.

## Update notes

- If you run 1.1.15 or 1.1.17, automatic updates cannot install from those builds. Download `PromeFTP-1.1.18-macos-arm64.dmg` from the Assets of this release, check it against the `.sha256` file, and replace the app in Applications once. Later updates install automatically.
- Close active sessions before updating.
- Requires macOS 13 or later on Apple Silicon.
