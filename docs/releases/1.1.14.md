# PromeFTP 1.1.14

## What's new

- SFTP: pressing **Reconnect** on a split remote pane keeps the tab on screen. Before, the tab's content disappeared after reconnecting, and clicking the reconnected file pane hid it again.
- Agents: when a bookmark grant allows downloads, you can set the largest file an agent may download (1–1024 MiB, 16 by default) and how many files may wait in the staging folder (1–256, 64 by default) in Settings → Agents → SFTP. Grants saved by earlier versions keep the previous limits. A download must still finish within the 30-second request limit.
- Agents: the bundled skill now tells agents to inspect remote files over SSH with read-only commands before reading or downloading them, and to ask you instead of downloading when SSH is not allowed. Skills set to update automatically pick this up; otherwise reinstall the skill from Settings → Agents.

## Known issues

- Korean, Chinese, and Japanese text in the terminal is wide with the default Menlo font. Choose a monospaced font that includes these characters in Settings → Terminal.
- Some labels in Korean, Japanese, and Chinese are machine translated and may read awkwardly.

## Update notes

- Close active sessions before updating.
- Requires macOS 13 or later on Apple Silicon.
