# PromeFTP 1.1.7

## What's new

- Agents: connections use the host keys you already trusted in PromeFTP, so a trusted server no longer fails as an unknown host.
- Agents: when a connection fails, the session reports the cause instead of a generic error. The causes include a wrong key or password, a changed or unknown host key, a refused connection, a DNS failure, and a connection the server closed during the handshake. Each cause comes with a short hint. `promeftp session status --json` returns the code, stage, and hint under `error`.
- Agents: a bookmark whose folder is a symbolic link can browse the folder it points to, inside the root you granted.
- Agents: permission presets, including an "allow everything" preset, make it faster to grant a bookmark. Access is still limited to the scope you choose.
- Preferences → Shortcuts: every shortcut can be changed, and a key check shows which key your keyboard sends. Default shortcuts are unchanged.
- Preferences → Authentication: rules and saved answers are listed by host, and the rule editor is redesigned.
- Preferences → Agents: bookmark access fields stay enabled, and each field explains what it does.
- Snippets: the first search result is selected automatically, and the editor opens in its own sheet.
- Tooltips stay inside the window, close when the pointer leaves, and are smaller.
- The SFTP folder tree and the folder compare button use different icons.

## Known issues

- Some labels in Korean, Japanese, and Chinese are machine translated and may read awkwardly. Native-speaker corrections are welcome.
- A bookmark that uses an SSH alias or a different HostName may show an "untrusted host key" banner even when the key is trusted.

## Update notes

- Close active sessions before updating.
- Requires macOS 13 or later on Apple Silicon.
