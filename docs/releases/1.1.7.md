# PromeFTP 1.1.7

- Agents: a bookmark that the app already trusted no longer fails with "unknown host key". Agent connections use the host keys you trusted in PromeFTP. A bookmark whose folder is a symbolic link can now browse the folder it points to, inside the root you granted.
- Agents: when a connection fails, the session reports a specific reason instead of a generic error: a wrong key or password, a changed or unknown host key, a refused connection, a DNS failure, or a handshake that the server closed. Each reason comes with a short hint. `promeftp session status --json` returns the code, stage, and hint under `error`.
- Agents: permission presets, including an "allow everything" preset, make it faster to grant a bookmark. Access is still limited to the scope you choose.
- Preferences → Authentication: each rule and saved answer is listed with its host, and the rule editor is redesigned. Bookmark access fields are no longer disabled without a reason.
- Preferences → Shortcuts: every shortcut can be changed, and a key diagnostic shows which key your keyboard sends. Default shortcuts are unchanged.
- Preferences → Terminal and Snippets: the Snippets window selects the first search result automatically and keeps the editor in its own sheet.
- Tooltips stay inside the window, close when the pointer leaves, and are smaller.
- The SFTP folder tree and the folder compare button use different icons. The sidebar button for authentication is named "Authentication".
- Update the user guide for the new error hints and shortcut settings.

Requires macOS 13 or later on Apple Silicon. See the [user guide](../USAGE.md), [agent setup](../AGENTS.md), and [install guide](../INSTALL.md).
