# PromeFTP 1.1.1

This release improves SFTP transfers and folder comparison. You can keep browsing while transfers run, review exactly which files will be copied, and retry interrupted work from the transfer drawer.

- **Transfer drawer.** See progress, paths, and errors. Pause, cancel, or retry work individually or as a group. Transfers on other connections can continue while a file conflict awaits an answer.
- **Folder comparison.** Compare local and remote folders or two connected remote folders. Select the files to copy, review size and modification time, and cancel the validation scan before queueing. Files that exist only at the destination are preserved.
- **Safer copies.** PromeFTP checks paths for case and Unicode name collisions and checks file metadata against the preview before copying. Remote Keep Both requires server support for the OpenSSH hard-link extension.
- **Recovery and navigation.** File menu transfers retain the connection identity for retries. Folder favorites can be renamed, edited, reordered, or removed without changing the folders themselves.

Requires macOS 13 or later on Apple Silicon. Existing installations can use **Check for Updates…**. The [source](https://github.com/PROMLEE/promeftp/tree/v1.1.1) is available under the [MIT License](https://github.com/PROMLEE/promeftp/blob/v1.1.1/LICENSE).
