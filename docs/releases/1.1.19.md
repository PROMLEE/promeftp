# PromeFTP 1.1.19

## What's changed

- Agent tabs: every agent session now gets a tab when the agent asks for it, including SFTP-only sessions and sessions waiting for a PAM or OTP answer. The tab header shows the client, bookmark, user@host, mode, and the access the grant allows. Status lines show connecting, waiting for an answer (with the question), and connected. SFTP list, stat, and download activity is shown with its path and result, including denied paths and the reason.
- Favorites: you can rename an SFTP folder favorite again from the popover row menu and the favorites menu. The full path wraps instead of being cut off.
- Path bar: deep paths keep the root, the first folder, and the last two folders visible. The folders in between sit behind an ellipsis menu.
- Back and forward: the file panes have Back and Forward buttons. They can be hidden or moved in the toolbar customization list. Mouse back and forward buttons go one step per press, and a checkbox in Settings → Shortcuts turns them on or off (on by default).
- Parent folder: double-click or Enter on `..` opens the parent folder. A single click only selects it.
- Dock menu: right-clicking the PromeFTP Dock icon shows New Window.

## Known issues

- Korean, Chinese, and Japanese text in the terminal is wide with the default Menlo font. Choose a monospaced font that includes these characters in Settings → Terminal.
- Some labels in Korean, Japanese, and Chinese are machine translated and may read awkwardly.

## Update notes

- Close active sessions before updating.
- Requires macOS 13 or later on Apple Silicon.
- Updates from PromeFTP 1.1.18 install automatically from this release.
