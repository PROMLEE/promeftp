# PromeFTP 1.1.16

## What's new

- Bookmarks: drag a bookmark **folder** by its heading to reorder folders. Drop it on the upper half of another folder's heading to place it above that folder, or on the lower half to place it below.
- Bookmarks: drag a **bookmark** above or below another bookmark to place it there. Dropping it on a bookmark in another folder moves it into that folder at that spot. Dropping it on the empty space below the list moves it to the top level, last.
- The bookmark order is saved in the app state, so it survives a restart and applies to every window. Earlier builds kept the order only in each window; that order is carried over once on first launch. Folders you had not reordered keep their name order.
- Workspaces: **Update with Open Tabs…** in a saved workspace's context menu (sidebar or manager) overwrites that workspace with the non-agent tabs open in the current window. Saving the workspace manager form under an existing name now updates that workspace instead of failing.
- Bookmarks: favorite paths show in full.
- Pane notices appear at the bottom of the pane.

## Known issues

- Korean, Chinese, and Japanese text in the terminal is wide with the default Menlo font. Choose a monospaced font that includes these characters in Settings → Terminal.
- Some labels in Korean, Japanese, and Chinese are machine translated and may read awkwardly.

## Update notes

- Close active sessions before updating.
- Requires macOS 13 or later on Apple Silicon.
