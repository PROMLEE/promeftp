# PromeFTP 1.1.17

## What's changed

- SSH host keys: when you check **Don’t ask again for this server, even if its key changes**, PromeFTP accepts a changed key for that server without asking again. The tab shows that a changed key was accepted. Earlier builds asked again on every connection after the server's key changed, even when the box was checked.
- Without that checkbox, PromeFTP still asks you to verify a key that differs from the one you trusted.

## Known issues

- Korean, Chinese, and Japanese text in the terminal is wide with the default Menlo font. Choose a monospaced font that includes these characters in Settings → Terminal.
- Some labels in Korean, Japanese, and Chinese are machine translated and may read awkwardly.

## Update notes

- Close active sessions before updating.
- Requires macOS 13 or later on Apple Silicon.
- Check **Don’t ask again for this server, even if its key changes** only for a server you trust. A changed key can be a sign of a man-in-the-middle attack, and PromeFTP will not ask about it for that server.
