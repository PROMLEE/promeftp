# PromeFTP 1.0.3

Create terminal triggers from selected output, edit saved snippets, and control Keychain access for SSH connections.

- **Terminal triggers.** Select text in an SSH or local terminal, right-click, and choose **Create Trigger from Selection…**. PromeFTP escapes the selection into an editable RE2 pattern. Matches in new output appear in the pane’s **Triggers** indicator. Use **Terminal Triggers…** to edit rules or review recent matches.
- **Editable snippets.** Press **⌘P** and use the pencil button to change an existing snippet’s name, command, or scope.
- **Keychain controls.** Open **Preferences → Authentication → Keychain** to control OpenSSH Keychain access and loading saved PAM answers independently. OpenSSH Keychain access is off by default. Explicitly saving or revealing a PAM answer still uses Keychain.
- **Alignment.** Connection option labels, PAM icon buttons, and SFTP path and file labels align more consistently.

Close active sessions and choose **PromeFTP → Check for Updates…**. For a new installation, download the Apple Silicon DMG. Requires macOS 13 or later.
