# PromeFTP 1.1.6

- Transfers: finished transfers no longer reappear when the app starts. The Transfers drawer lists only running, paused, failed, and interrupted work, closes by itself after everything succeeds, and shows a count on the toolbar button (red when something failed). Finished transfers are kept for 30 days in a searchable History tab. Rows and progress bars are aligned, and the header can clear failed items.
- If PromeFTP quits during a transfer, that transfer is kept as interrupted. A notice at the next startup offers to retry it after you reconnect SFTP.
- ⌘P now matches the physical key, so Snippets opens while a Korean or other non-Latin input source is active. ⌘⇧P is a second shortcut. Dvorak, Colemak, AZERTY, and German layouts keep their own letters and symbols. Opening Snippets no longer closes other open dialogs.
- Preferences → Terminal: choose between a limited scrollback and unlimited scrollback with a clear explanation of the memory cost.
- Preferences → Authentication: the master switch "Use saved authentication" now sits first and dims the sections it controls. Rules that apply to every host are named "All-Host Rules"; saved answers for one host are "Per-Host Answers". Info buttons explain each option.
- Preferences → Agents: each problem is shown next to its field in plain language, and saving shows a "saved" confirmation. SFTP browsing is off by default for new grants, and permissions are grouped into SFTP, SSH commands, and authentication and triggers. Info buttons explain 14 options.
- Preferences → About: a centered layout with a Copy button for version, build, and system details, and a single update card.
- Update the user guide for the new transfer and shortcut behavior.

Requires macOS 13 or later on Apple Silicon. See the [user guide](../USAGE.md), [agent setup](../AGENTS.md), and [install guide](../INSTALL.md).
