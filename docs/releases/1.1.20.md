# PromeFTP 1.1.20

## What's changed

- SFTP buttons no longer freeze after the connection sits idle. If the network drops without a reset (sleep, Wi-Fi change), PromeFTP now detects it about 45 seconds later, closes the SFTP session, and shows the Reconnect button.
- Each SFTP request now gives up after 60 seconds with a message asking you to reconnect and try again, so a stuck server can no longer leave the toolbar and Refresh disabled.
- The folder tree has a draggable divider, and you can also use the arrow keys to resize it. The width is shared by every file pane and saved on this device.
- The column headers and the filter sit beside the folder tree, so they move with the rows when the tree opens.
- The path bar shows every folder that fits. Only when a path is too wide do the middle folders move behind an ellipsis menu, and the folders next to the current one stay visible.

## Known issues

- Korean, Chinese, and Japanese text in the terminal is wide with the default Menlo font. Choose a monospaced font that includes these characters in Settings → Terminal.
- Some labels in Korean, Japanese, and Chinese are machine translated and may read awkwardly.

## Update notes

- Close active sessions before updating.
- Requires macOS 13 or later on Apple Silicon.
- Updates from PromeFTP 1.1.19 install automatically from this release.
