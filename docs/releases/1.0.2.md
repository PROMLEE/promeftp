# PromeFTP 1.0.2

This release makes dark mode brighter and expands terminal font selection to the families installed on your Mac.

- **Preferences → About** shows the running version and build, macOS version, last update check, automatic installation settings, and license notices. Open release notes, the user guide, or GitHub from the same tab.
- **Preferences → Terminal** offers System Monospace, installed font families, and a custom family field. Preview your choice and click **Save** to apply it to open terminals.
- Preferences, the sidebar, and terminals use lighter dark backgrounds. Opening Preferences no longer forces keyboard focus onto the General tab.

Close active sessions and choose **PromeFTP → Check for Updates…**. For a new installation, download the Apple Silicon DMG and follow the install guide. The release requires macOS 13 or later.
