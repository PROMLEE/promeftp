# PromeFTP 1.0.8

터미널 트리거 관리와 북마크 저장 동작을 더 명확하게 정리했습니다.

- **⌘P로 터미널 트리거 열기.** 스니펫은 사이드바와 터미널 도구막대에서 엽니다.
- **트리거 추가·수정 창 분리.** 규칙마다 이름, 패턴, 동작, 적용 범위를 별도 창에서 편집합니다. 실행 내역은 터미널 위 배너 대신 트리거 목록의 최근 일치 항목에서 확인합니다.
- **북마크 덮어쓰기 방지.** 선택한 북마크는 **Save Changes**로 수정하고, **Save as New Bookmark**로 별도 저장합니다. 북마크 우클릭 메뉴에서 이름을 지정해 복제할 수도 있습니다.
- **워크스페이스 표시 개선.** 이름과 탭 수를 분리하고 탭이 하나일 때 단수로 표시합니다.

업데이트 전 활성 세션을 닫으세요. 신규 설치는 Apple Silicon용 DMG를 받으세요. macOS 13 이상이 필요합니다.
