# PromeFTP 1.1.2

- Grant agent access to saved OpenSSH aliases from Settings → Agents. Connections use the bookmark's OpenSSH configuration. Save access again if the resolved configuration changes.
- Copy a new agent token from its registration window. The app displays it once and closing the window ends access to the displayed token. The clipboard has no automatic expiry.
- Localize agent setup and bookmark actions and align the activity retention controls.

Requires macOS 13 or later on Apple Silicon. Agent connections require trusted host keys. The source is available under the [MIT license](https://github.com/PROMLEE/promeftp/blob/v1.1.2/LICENSE).
