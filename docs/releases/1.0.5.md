# PromeFTP 1.0.5

This release improves connection setup and SFTP navigation.

- **Expand an OpenSSH alias to its address.** In the connection form, choose **Use address** to replace the selected alias with its resolved hostname or IP. PromeFTP also fills an empty user, port, and identity field from the effective OpenSSH configuration. You can then edit the destination directly.
- **Navigate SFTP paths with mouse buttons.** Use the mouse Back and Forward buttons over either file panel to revisit paths in that panel. The history is independent for local and remote browsing.
- **Copy full file paths.** Right-click a local or remote file or folder and choose **Copy Path**.
- **Clear file selection quickly.** Click unused space in a file list to clear its current selection.
- **Move remote SFTP panels.** Drag a panel by its grip to rearrange remote panes in the same tab. The local browser remains shared.
- **Refresh visible terminal panes when returning to a tab.** This fixes blank terminal panes after switching between tabs and connections.

Close active sessions and choose **PromeFTP → Check for Updates…**. For a new installation, download the Apple Silicon DMG. Requires macOS 13 or later.
