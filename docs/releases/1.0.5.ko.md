# PromeFTP 1.0.5

연결 설정과 SFTP 탐색을 개선했습니다.

- **OpenSSH 별칭을 실제 주소로 변환.** 연결 화면에서 **Use address**를 누르면 별칭이 유효 hostname/IP로 바뀝니다. 사용자, 포트, 키 입력란이 비어 있으면 OpenSSH 설정에서 해석한 값도 채웁니다.
- **마우스 버튼으로 SFTP 경로 이동.** 파일 패널 위에서 마우스 뒤로/앞으로 버튼을 눌러 해당 패널의 방문 경로를 이동합니다. 로컬과 원격 경로 기록은 각각 관리됩니다.
- **전체 파일 경로 복사.** 로컬 또는 원격 파일·폴더를 우클릭하고 **Copy Path**를 선택합니다.
- **선택 빠른 해제.** 파일 목록의 빈 공간을 클릭하면 선택 항목이 해제됩니다.
- **원격 SFTP 패널 이동.** 패널 손잡이를 끌어 같은 탭 안에서 원격 패널 순서를 바꿀 수 있습니다. 로컬 탐색기는 공유됩니다.
- **탭 전환 후 터미널 복구.** 탭으로 돌아오면 표시 중인 터미널의 크기와 화면을 다시 맞춥니다.

활성 세션을 닫은 뒤 **PromeFTP → Check for Updates…**를 선택하세요. 새로 설치하려면 Apple Silicon DMG를 받으세요. macOS 13 이상이 필요합니다.
