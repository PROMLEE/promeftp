# PromeFTP 1.0.1

PromeFTP now opens Preferences in a separate macOS window. Press **⌘,** to open General, Terminal, Authentication, Shortcuts, or About while keeping your workspace visible.

- **General → Language** offers English, Korean, Japanese, Simplified Chinese, and the macOS language. Click **Save** to apply your choice to Preferences and the main interface. Server prompts and terminal output remain in their original language.
- **Authentication** brings together saved PAM answers, global rules, and automatic replies. **Shortcuts** lists keyboard commands in the same window.
- Existing terminal settings carry forward. Saving font and scrollback changes applies them to open terminals.

Close active sessions and choose **PromeFTP → Check for Updates…**. For a new installation, download the Apple Silicon DMG and follow the installation guide.
