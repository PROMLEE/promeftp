# PromeFTP 1.1.12

## What's new

- SSH config: search aliases by host name or IP address and by user, not only by alias name. Type part of an address such as `10.0.1`, or several words such as `deploy 10.0`; every word must match. Each alias shows its host name under the name, so you can see why it matched.
- SSH config: the values come from `ssh -G`, so they include `Match`, `Include`, and wildcard settings. The alias list appears right away, and host names fill in a moment later.
- The host picker for split panes uses the same search.

## Known issues

- An alias without a `User` line is resolved to your macOS user name, so searching for that name lists those aliases too.
- Some labels in Korean, Japanese, and Chinese are machine translated and may read awkwardly.

## Update notes

- Close active sessions before updating.
- Requires macOS 13 or later on Apple Silicon.
