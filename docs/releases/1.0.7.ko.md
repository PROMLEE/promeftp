# PromeFTP 1.0.7

터미널 트리거, 비밀번호 저장 안내, 워크스페이스 동작을 개선했습니다.

- **여러 줄 트리거 응답.** 저장 응답의 각 줄을 Return과 함께 전송하며, 마지막 줄바꿈 때문에 빈 명령을 추가로 보내지 않습니다.
- **트리거를 Snippets 옆에서 관리.** SSH 도구 막대의 Terminal Triggers에서 최근 일치 내역을 보고 규칙을 켜거나 끌 수 있습니다. 규칙 상태는 재실행 후에도 유지됩니다.
- **비밀번호 저장 결과 표시.** 입력한 비밀번호는 연결 창에 남습니다. 저장 완료, SSH 재요청, 서버의 미요청, 저장 실패를 구분해 보여줍니다. 거부된 비밀번호는 나중에 수동 재시도가 성공해도 저장하지 않습니다.
- **사이드바 선택과 기록 순서 유지.** 선택한 북마크, 기록, 워크스페이스 탭을 재실행 후 복원합니다. 기록은 최신순으로 유지하고 드래그 순서 변경을 막습니다.
- **기존 세션 유지.** 저장한 워크스페이스를 열어도 실행 중인 세션을 닫지 않습니다.

업데이트 전에 연결된 세션을 닫으세요. 새로 설치하려면 Apple Silicon DMG를 받으세요. macOS 13 이상이 필요합니다.
