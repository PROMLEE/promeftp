# PromeFTP 1.1.5

- Fix ⌘P in the application menu. Version 1.1.4 still opened Terminal Triggers from the menu even though the SSH terminal opened Snippets. ⌘P now opens Snippets from both the menu and the terminal. Terminal Triggers have no keyboard shortcut and open from the SSH toolbar button or the terminal context menu.
- Preferences → Shortcuts shows "No shortcut" (translated) for actions without a keyboard shortcut.
- Align the Preferences tab bar and controls.
- Quick Guide: add a Transfer queue and folder compare section, fix the scroll layout of the guide dialog, and announce empty search results to screen readers.
- SFTP file rows: rename with F2 and move to Trash or delete with ⌘Delete, matching the context menu.
- Show a focus ring on buttons and text fields more clearly.
- Keep the sidebar usable at its minimum width: fit the segmented tabs, wrap long workspace names, and keep footer icons inside the sidebar.
- Correct the documentation for ⌘P, the reconnect message, and the 1.1.5 release references.

Requires macOS 13 or later on Apple Silicon. See the [user guide](../USAGE.md), [agent setup](../AGENTS.md), and [install guide](../INSTALL.md).
