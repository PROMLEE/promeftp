# PromeFTP 1.1.5

- Fix ⌘P in the application menu. Version 1.1.4 still opened Terminal Triggers from the menu even though the SSH terminal opened Snippets. ⌘P now opens Snippets from both the menu and the terminal. Terminal Triggers have no keyboard shortcut and open from the SSH toolbar button or the terminal context menu.
- Correct the 1.1.4 release notes and documentation: README, the user guides, and the LLM reference files now describe ⌘P as Snippets.
- Quick Guide now has a Transfer queue and folder compare section. Reconnect guidance matches the message the app shows.
- Preferences → Shortcuts shows "—" for actions without a keyboard shortcut.
- Quick Guide search no longer rebuilds every section on each keystroke.

Requires macOS 13 or later on Apple Silicon. See the [user guide](../USAGE.md), [agent setup](../AGENTS.md), and [install guide](../INSTALL.md).
