# PromeFTP 1.1.13

## What's new

- Agents: when an agent opens an SSH session through the `promeftp` CLI, PromeFTP adds a tab for it in the main window. The tab shows each command the agent runs and its output as it happens, with errors and exit codes marked. The new tab does not take focus; a dot shows it has activity.
- Agents: you can type in that tab. It is a separate shell on the same connection, so it does not ask for your password or OTP again. What you type is not sent to the agent or recorded in the activity log. Closing the tab ends the agent session.
- Agents: when PromeFTP denies an agent request, the error now says why, for example no permission for this bookmark, the bookmark changed since permission was given, or SSH not allowed.
- Bookmarks: double-click a bookmark to open an SSH tab.

## Known issues

- Korean, Chinese, and Japanese text in the terminal is wide with the default Menlo font. Choose a monospaced font that includes these characters in Settings → Terminal.
- Some labels in Korean, Japanese, and Chinese are machine translated and may read awkwardly.

## Update notes

- Close active sessions before updating.
- Requires macOS 13 or later on Apple Silicon.
