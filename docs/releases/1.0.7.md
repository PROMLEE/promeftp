# PromeFTP 1.0.7

This release improves terminal triggers, password feedback, and workspace navigation.

- **Send multiline trigger replies.** Saved trigger replies can contain multiple lines. PromeFTP sends each line with Return and avoids sending an extra empty command when the reply ends with a newline.
- **Manage triggers beside Snippets.** Open Terminal Triggers from the SSH toolbar, review recent matches, and enable or pause each rule. Trigger state persists across restarts.
- **See the actual password outcome.** The entered password remains in the connection form. PromeFTP reports when it was saved, when SSH asked for it again, when the server did not request it, and when saving failed. A rejected password is never saved after a later manual retry.
- **Keep sidebar selection and history order.** The selected Bookmarks, History, or Workspaces tab returns after restart. History stays newest first and cannot be reordered by dragging.
- **Keep existing sessions when opening a workspace.** Opening a saved workspace adds its tabs without closing running sessions.

Close active sessions before updating. For a fresh installation, download the Apple Silicon DMG. Requires macOS 13 or later.
