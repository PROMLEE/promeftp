# PromeFTP 1.1.0

로컬 CLI와 API를 추가해, 권한을 부여한 연결을 호환되는 AI 에이전트에서 사용할 수 있습니다.

- **에이전트와 북마크별 권한.** 에이전트 접근은 기본으로 꺼져 있습니다. 클라이언트를 등록하고 사용할 연결과 기능을 각각 지정합니다.
- **승인 범위가 보이는 SSH 실행.** 고정 명령 작업을 제공하거나, 실행할 명령을 건별로 확인한 뒤 전송합니다. 명령은 원격 계정 권한으로 실행됩니다.
- **제한된 SFTP.** 허용한 폴더의 목록과 정보를 조회하며, 다운로드는 별도 권한으로 제어합니다. 에이전트 SFTP API에는 원격 파일 수정·삭제 기능이 없습니다.
- **PAM 및 터미널 트리거.** 에이전트가 사용할 저장 인증 규칙과 트리거 알림을 선택할 수 있습니다.
- **활동 이력.** 요청, 권한, 승인, 세션 및 결과를 로컬에 기록하며 자격 증명, 터미널 출력, 임의 SSH 명령 텍스트는 저장하지 않습니다.
- **에이전트 스킬 설치.** Codex, Claude Code, Cursor, Gemini CLI, GitHub Copilot CLI용 PromeFTP 스킬을 사용자 또는 프로젝트 범위에 설치하고 업데이트할 수 있습니다.

에이전트 접근은 기본으로 꺼져 있으며 PromeFTP가 실행 중이어야 합니다. 에이전트 세션은 사용자 이름이 명시된 직접 북마크를 지원합니다. OpenSSH 별칭, 별도 SSH 설정 파일, 프록시와 점프 호스트는 에이전트 연결에서 지원하지 않습니다. SSH 명령의 권한은 원격 계정에 따릅니다. macOS 13 이상 Apple Silicon에서 사용할 수 있습니다.
