# PromeFTP 1.0.4

This release improves SFTP file handling and tab group workflows.

- **Safer local rename.** Renaming a local item to an existing name now stops with an error instead of replacing that item.
- **Remote file editing.** Open a remote file in the default text editor, choose whether to upload the saved copy, and keep a local recovery copy if the upload is skipped or fails.
- **Tab group filtering.** New connections open in the selected group so they remain visible while a group filter is active.
- **New app icon.** The PromeFTP mark combines a letter P, a file corner, and a transfer arrow.

Close active sessions and choose **PromeFTP → Check for Updates…**. For a new installation, download the Apple Silicon DMG. Requires macOS 13 or later.
