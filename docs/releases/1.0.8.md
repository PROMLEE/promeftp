# PromeFTP 1.0.8

This release makes terminal trigger rules easier to manage and separates bookmark updates from creating new bookmarks.

- **Open Terminal Triggers with ⌘P.** The shortcut opens the trigger list from an SSH session. Snippets remain available from the sidebar and terminal toolbar.
- **Edit triggers in a dedicated dialog.** Add and edit each rule in a separate popup with a required name, match pattern, action, and scope. Trigger matches remain in the activity list without adding a banner to the terminal toolbar.
- **Keep bookmark saves explicit.** **Save Changes** updates the selected bookmark. **Save as New Bookmark** creates a separate entry, and the bookmark context menu can duplicate an entry by name.
- **Improve workspace readability.** Workspace names and tab counts are separated, and a single tab is labeled correctly.

Close active sessions before updating. For a fresh installation, download the Apple Silicon DMG. Requires macOS 13 or later.
