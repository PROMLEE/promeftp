# PromeFTP 1.1.11

## What's new

- SFTP: file lists refresh by themselves after an upload, download, copy between servers, new folder, or backup finishes. A refresh is no longer dropped while another remote action is running.
- SFTP: the local file browser can be split again and again, up to six panes. Each local pane has **Split Right** and **Split Down** buttons, and the full split layout is saved with workspaces. Workspaces saved with 1.1.10 open as before.
- Interface: button tooltips that appeared in English are now translated into Korean, Japanese, and Simplified Chinese, including the SFTP split buttons and folder tree expand/collapse labels.

## Known issues

- Six side-by-side panes can be narrow in a small window. Mix split directions or drag the dividers to resize.
- Some labels in Korean, Japanese, and Chinese are machine translated and may read awkwardly.

## Update notes

- Close active sessions before updating.
- Requires macOS 13 or later on Apple Silicon.
