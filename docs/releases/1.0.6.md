# PromeFTP 1.0.6

This release makes OpenSSH alias setup clearer and easier to edit.

- **Put the connection name first.** The Name field now appears above the destination. Selecting an OpenSSH alias uses the alias as the default display name.
- **Fill resolved settings as editable values.** Hostname or IP, user, port, and identity file from OpenSSH config are placed directly in their fields instead of appearing as gray placeholders. You can edit them, and clearing an override returns to the config value. The alias remains active so alias-specific OpenSSH rules continue to apply.
- **Keep direct address conversion.** Choose **Use address** when you want to replace the alias destination with the resolved address.

Close active sessions and choose **PromeFTP → Check for Updates…**. For a new installation, download the Apple Silicon DMG. Requires macOS 13 or later.
