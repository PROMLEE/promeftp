# PromeFTP 1.1.10

## What's new

- SFTP: right-click a remote file or folder and choose **Backup** to make a copy next to it named `name.YYYYMMDD-HHMMSS`. A second backup in the same second gets `-2`. Permissions and modification times are kept. On servers that do not allow shell commands, PromeFTP copies the file through the app instead and restores its permissions and times.
- SFTP: the local file browser can be split into two panes, side by side or stacked. Drop remote files on either pane to download there. The split is saved with workspaces.
- File transfers: when a file with the same name exists, the dialog shows the size and modification time of both files and offers **Replace if newer**. Check **Apply to the rest of this transfer** to answer once for a multi-file transfer, or **Remember this choice** to stop asking. Change or reset the saved choice in Settings → General → File Transfers.
- File transfers: downloading from the context menu no longer asks a second time after you confirm replacement in the macOS save dialog.
- Agents: the settings page was reorganized. Bookmarks are listed directly with their access status, a bookmark keeps its access after you rename it or move it to a folder, and settings below the main switch are disabled while access is off.
- Agents: if the agent service cannot start (for example, another PromeFTP still holds the socket after an update), the switch keeps its saved value and the page shows the reason with a **Try Again** button. Startup also retries automatically.
- Agents: the Maximum preset now runs SSH commands without asking and trusts new host keys automatically, with warnings. Each command run this way is recorded in the activity history. Changed host keys still require a separate confirmation.

## Known issues

- The activity history in Settings shows the five most recent entries.
- Some labels in Korean, Japanese, and Chinese are machine translated and may read awkwardly.

## Update notes

- Close active sessions before updating.
- Requires macOS 13 or later on Apple Silicon.
