# PromeFTP 사용 가이드

[설치와 첫 실행](INSTALL.ko.md) · [0.0.3 베타 릴리스](https://github.com/PROMLEE/promeftp/releases/tag/v0.0.3)

## 호스트 연결

1. 왼쪽 **Hosts**에서 기존 호스트를 선택하거나 **+**를 누릅니다.
2. 서버 주소를 입력합니다. 필요하면 사용자, 포트, 개인 키를 지정합니다.
3. **SSH** 또는 **SFTP**를 누릅니다. 북마크 아이콘으로 호스트를 저장합니다. 아이콘에 포인터를 올리면 짧은 툴팁이 표시됩니다.

게이트웨이 주소처럼 `@`가 포함된 접속 문자열을 Host 칸에 붙여넣으면, 마지막 `@`를 기준으로 SSH 호스트와 로그인 문자열을 미리 볼 수 있습니다. **Split address**를 누르면 두 값을 Host와 User 칸에 채웁니다.

### OpenSSH 설정

OpenSSH 별칭은 왼쪽 아래 **OpenSSH config** 아이콘에서 선택합니다. 별칭 목록은 `~/.ssh/config`의 구체적인 `Host` 이름과 `Include`를 읽습니다. 선택한 별칭과 해석된 Hostname 또는 IP는 연결 화면에서 별도로 표시됩니다. 와일드카드에 맞는 별칭은 서버 주소에 직접 입력할 수 있습니다. 다른 파일 선택과 `ssh -G` 미리보기는 연결 폼의 **Options**에 있습니다.

별칭을 고르면 OpenSSH가 해석한 **Hostname / IP**, **User**, **Port**를 각 입력란에 기본값으로 표시합니다. **SSH alias**를 유지한 채 원하는 값만 입력해 덮어쓸 수 있습니다. 입력값을 지우면 SSH 설정의 값을 다시 사용합니다. 호스트나 워크스페이스를 저장하면 입력한 값도 함께 저장됩니다.

SSH와 SFTP는 모두 macOS의 `/usr/bin/ssh`를 사용합니다. 호스트 키 검증, `known_hosts`, `IdentityFile`, `ProxyJump`, `ProxyCommand`는 OpenSSH가 처리합니다. 앱은 인증된 채널을 관리하기 위해 연결별 제어 소켓을 지정합니다. SFTP는 전송용 연결을 열고 그 채널에서 파일 프로토콜을 시작합니다. SSH와 SFTP 연결에서 포트 전달은 비활성화됩니다. SFTP에서는 설정의 원격 셸 명령도 비활성화됩니다. 앱은 설정 파일을 편집하지 않으며, OpenSSH는 호스트 키 정책에 따라 `known_hosts`를 갱신할 수 있습니다.

## SFTP 파일 작업

- **왼쪽 Local**은 SFTP 탭이 열리면 홈 폴더를 표시합니다. 인증 중에도 왼쪽을 탐색할 수 있습니다. 숨김 항목은 눈 아이콘으로 표시합니다.
- **오른쪽 Remote**는 인증 후 서버의 기본 폴더를 표시합니다. 두 패널의 상단 경로에서 폴더 이름을 클릭하면 해당 폴더로 이동합니다. 연필 아이콘으로 경로를 직접 입력하고, 시계 아이콘으로 최근 경로를 다시 엽니다. 로컬 패널의 폴더 아이콘은 Finder 폴더 선택창을 엽니다. 최근 경로는 이 Mac에 저장되며 원격 경로는 접속 설정별로 구분합니다.
- 각 패널의 **Toggle folder tree** 아이콘으로 폴더 트리를 켭니다. 화살표로 하위 폴더를 펼치고 폴더 이름을 눌러 이동합니다.
- 목록 맨 위의 **..**로 상위 폴더에 이동합니다. 나머지 항목은 이름순으로 표시되고, 파일 아이콘은 확장자에 따라 구분됩니다. 폴더는 더블클릭하거나 이름에 초점을 두고 Return을 누릅니다.
- 체크박스로 파일·폴더를 여러 개 고른 뒤 양쪽 상단의 전송 화살표를 누르거나 반대쪽 패널로 끌어 놓습니다. 대상은 반대쪽 패널에 현재 열린 폴더입니다.
- 원격 폴더 생성, 이름 변경, 파일 및 빈 폴더 삭제를 지원합니다. 파일 전송은 원본을 유지합니다. 같은 이름의 원격 파일에 업로드할 때 **Skip** 또는 **Replace**를 선택합니다. **Replace**는 새 파일을 모두 전송한 뒤 교체합니다. 서버가 교체를 거부하면 기존 파일을 보존합니다. 같은 이름의 폴더와 다운로드 대상은 덮어쓰지 않습니다. 폴더 전송에서 심볼릭 링크는 따라가지 않으며, 실패 전에 완료된 항목은 대상에 남을 수 있습니다.

## 탭과 워크스페이스

- 탭의 **⋯** 또는 우클릭 메뉴에서 이름, 색상, 그룹을 지정합니다. 탭을 드래그하면 순서를 바꿀 수 있으며 다른 그룹의 탭 위에 놓으면 그 그룹으로 이동합니다.
- 터미널에서 **Split Right**(⌘D) 또는 **Split Down**(⌘⇧D)을 누르면 같은 접속 설정으로 새 연결을 열어 현재 탭 안에 추가합니다. 서버가 요구하는 PAM 질문은 새 연결에서 다시 표시됩니다. 각 구분선을 드래그하거나 화살표 키로 크기를 조절하고, 각 터미널의 **Close Pane**으로 해당 연결만 닫습니다.
- 상단의 **Workspaces → Save layout**은 탭 이름과 색상, 그룹과 순서, 분할 방향과 크기, SFTP 양쪽 경로를 저장합니다.
- 이미 저장한 작업공간에서 **Update Layout**을 누르면 같은 항목을 갱신합니다. **Save as New**는 현재 배치를 새 이름으로 복사합니다. 저장 목록에서 이름을 바꾸거나 저장본을 삭제할 수 있습니다.
- **Open**은 저장한 배치를 별도 작업공간으로 열고 탭마다 마지막으로 선택했던 분할 화면도 복원합니다. 이미 열려 있으면 **Switch**로 연결을 유지한 채 돌아갑니다. 저장본을 새로 열 때는 서버에 다시 연결하며, 원격 프로세스 상태와 이전 터미널 출력은 배치 복원 대상에서 제외됩니다.

## 터미널과 Oh My Zsh

- **⌘T** 또는 창 상단 터미널 아이콘으로 Mac 계정의 로그인 셸을 엽니다. 로그인 셸이 Zsh라면 기존 `.zprofile`, `.zshrc`와 그 안에서 설정한 Oh My Zsh 테마·플러그인·별칭·완성이 로드됩니다.
- SSH 탭에서는 서버의 로그인 셸과 설정이 적용됩니다. 원격에서 Oh My Zsh를 쓰려면 서버 계정에 설정되어 있어야 합니다. 로컬 셸 설정이나 플러그인은 서버에 복사하지 않습니다.
- 터미널을 우클릭하면 **Copy**, **Paste**, **Find**, **Clear Buffer**, **Clear Scrollback**, 분할 및 창 닫기 메뉴가 표시됩니다.
- **⌘F**는 출력 검색, **⌘D**는 새 연결을 열어 나란히 분할, **⌘K**는 스크롤백 정리입니다. **⌘+ / ⌘− / ⌘0**으로 글꼴 크기를 조절합니다. 터미널에서 **⌘클릭**으로 HTTP(S) 링크를 엽니다.
- **⌘,**에서 글꼴·크기·스크롤백·Option as Meta를 조절합니다. 테마의 기호가 깨지면 Mac에 설치된 Nerd Font를 지정할 수 있습니다. 셸이 OSC 133 프롬프트 마커를 출력하면 **⌘⌥↑ / ⌘⌥↓**로 이동합니다.
- 일반적인 ANSI 터미널과 셸 기능을 지원합니다. iTerm2 전용 기능인 tmux 통합 모드와 프로필 가져오기는 이 버전의 범위에 포함되지 않습니다. [Oh My Zsh 프로젝트](https://github.com/ohmyzsh/ohmyzsh)

## PAM과 자동 응답

서버가 SSH keyboard-interactive로 PAM 질문을 보내면 SSH와 SFTP의 연결 화면에 응답란이 자동으로 표시됩니다. 자동 응답 규칙은 질문에 미리 지정한 값을 보낼 때 사용합니다. 서버에서 요구하는 인증 순서와 PAM 정책은 서버 관리자가 설정합니다.

1. **Options → PAM rule**을 선택합니다.
2. 서버가 보여주는 질문과 응답을 입력합니다. 예를 들어 서버 질문이 `Verification code:`라면 해당 문구를 그대로 지정합니다. 앞뒤 공백과 OpenSSH가 붙이는 계정 접두사는 매칭에서 제외할 수 있습니다.
3. SSH 또는 SFTP로 연결합니다. 각 일치 규칙은 해당 연결에서 한 번만 사용됩니다. 일치하지 않는 질문은 별도 입력란에 표시됩니다.

**Save answer**를 선택하면 인증이 성공한 뒤 응답을 macOS 키체인으로 보호해 이 Mac에 암호화해 저장합니다. 같은 접속 설정과 질문에서 입력란을 채우며, **Reply**를 눌러 전송합니다. 체크를 해제하고 응답하면 해당 저장값을 삭제합니다. 한 번만 쓰는 OTP에는 체크를 해제해 두세요. 점프 호스트의 질문과 호스트 키 확인에는 저장 옵션을 표시하지 않습니다.

**Preferences → Authentication**에서 저장된 응답을 변경하거나 삭제할 수 있습니다. **Send automatically**를 켜면 호스트 키를 엄격하게 확인한 연결에서 같은 질문에 연결당 한 번 자동으로 답합니다. 같은 질문이 다시 표시되거나 저장값을 읽을 수 없으면 직접 답할 수 있습니다. 이전 개발 빌드에서 저장한 응답은 같은 질문을 다시 받으면 설정 목록에 표시됩니다.

자동 응답 모드에서는 OpenSSH에 엄격한 호스트 키 검증을 적용합니다. 미리 검증된 서버 키가 필요합니다. 대상 SSH 프로세스의 질문에만 자동 응답하며 점프 호스트의 질문과 확인 요청은 수동으로 처리합니다. 자동 응답 규칙의 입력값은 연결 폼에서 전송한 뒤 지우며 호스트 프로필, 워크스페이스, 세션 기록에 저장하지 않습니다.

## 권한과 업데이트

- 공식 앱 식별자는 `com.promlee.promeftp`입니다. 이후 버전도 같은 식별자와 고정 인증서를 사용합니다. 예전 임시 서명 빌드에서 넘어올 때 macOS가 파일 접근 권한을 다시 물을 수 있습니다.
- 앱은 SSH 개인 키와 호스트 신뢰를 시스템 OpenSSH에 맡깁니다. 사용자가 입력하는 제품 활성화 키는 없습니다. 앱 코드 서명과 Sparkle 업데이트 서명은 서로 다른 서명입니다.
- macOS 메뉴 **PromeFTP → Check for Updates…**에서 수동으로 확인합니다. **Install Updates Automatically**는 기본적으로 꺼져 있습니다. 켜면 Sparkle이 베타 업데이트를 확인·다운로드합니다. SSH, SFTP 또는 로컬 셸 세션이 열린 동안 설치·재실행을 미룹니다. 업데이트가 준비된 경우 앱을 종료할 때 설치될 수 있습니다.
- 업데이트는 PromeFTP 전용 HTTPS 베타 앱캐스트를 사용하며, Sparkle이 피드와 업데이트 ZIP의 Ed25519 서명을 확인합니다. 서명 실패나 다운로드 오류가 발생하면 기존 앱이 유지됩니다. 배포용 DMG와 ZIP의 SHA-256 파일은 같은 릴리스에 있습니다.
- 자체 서명과 Apple 공증은 별개입니다. 배포 빌드에는 Apple Developer ID 공증이 적용되지 않았습니다.
