Saving stores the plain-text token in a local 0600 file. PromeFTP CLI reads it automatically; the token is never written into skill files.
Forget saved token removes the local copy. Revoking its client also removes the saved token.
Without saving, copy the token before closing and provide it as PROMEFTP_AGENT_TOKEN. If lost, revoke and register the client again.

Bookmark access

Uses this bookmark's SSH settings.

OpenSSH aliases, Include, ProxyJump, and ProxyCommand are honored.
Target and jump host keys must be trusted. ProxyCommand may start a local process.
PAM login strings like account@host@account@host are accepted as SSH usernames.
